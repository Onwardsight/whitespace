# 留白（WhiteSpace）

> 给情绪留一点空间，也给自己留一点时间。

面向 **12–18 岁在校学生** 的情绪陪伴应用（Android）。

**没有账号，没有广告，没有排行榜。** 对话、树洞、日记只存在你自己的设备上。

## 它是什么

打开就是知序的一句问候，回它一句就能聊下去。也可以把说不出口的话写进**情绪树洞**（它会轻轻回你一声「回声」）、
在**泡泡天空**里点破那件压着你的小事、记一记今天的心情是什么**天气**，
或者让知序**记住**某些事 —— 记住什么由你自己决定，随时可以删。

## 隐私

- **没有账号**：我们不知道你是谁，也没有你的备份。
- **数据只在本机**：对话、树洞、日记、记忆都写在你自己的设备上，卸载即全部消失。
- **只有一件事会离开设备**：为了生成回应，「你刚说的那一句话」和一份记忆摘要会经过我们的服务器转交给模型，服务器**不保存**。
- **权限只有一项**：联网。没有通讯录、相册、定位、麦克风。
